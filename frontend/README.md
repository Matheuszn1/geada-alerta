# GeadaAlerta — Frontend

React 19 + Vite. Em desenvolvimento, as chamadas a `/api` são repassadas para o backend em `http://localhost:3333`
(veja `vite.config.js`).

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # build de produção em dist/
npm run lint    # oxlint
```

Instruções completas no [README da raiz](../README.md).
